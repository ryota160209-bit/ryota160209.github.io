プライバシーポリシー

lidar-logger（以下「本ツール」）は、開発者本人が自分の Raspberry Pi で使うための個人用ツールです。

  • アクセスするデータ：Google ドライブの権限は drive.file のみを使い、本ツール（rclone）が作成したファイルとフォルダにだけアクセスします。それ以外のファイルやアカウント情報は読み取りません。
  • データの利用目的：センサの計測結果（CSV ファイル）を利用者本人の Google ドライブに保存するためだけに使います。
  • 第三者への提供：Google のユーザーデータを第三者に送信・共有・販売しません。開発者のサーバーにも送信しません。
  • 保存：認証情報は利用者本人の Raspberry Pi の中にだけ保存されます。
  • アクセスの取り消し：Google アカウントの「サードパーティ製のアプリとサービス」からいつでも取り消せます。

本ツールによる Google API から取得した情報の使用は、Limited Use の要件を含む Google API Services User Data Policy に従います。

Privacy Policy

lidar-logger is a personal tool used only by its developer on their own Raspberry Pi.

  • Data accessed: Only the drive.file scope is used. The tool can access only files and folders it created, and reads no other files or account information.
  • Use: Solely to save sensor measurement results (CSV files) to the user's own Google Drive.
  • Sharing: Google user data is not transferred, shared or sold to any third party, and is not sent to any developer server.
  • Storage: Credentials are stored only on the user's own Raspberry Pi.
  • Revocation: Access can be revoked at any time from Google Account > Third-party apps & services.

lidar-logger's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
